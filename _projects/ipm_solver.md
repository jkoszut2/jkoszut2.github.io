This is a minimal Python implementation of a homogeneous self-dual embeddeding interior-point method (HSDE-IPM) for conic programming over the nonnegative orthant and Lorentz cone developed as part of the class project for 6.7230 (Algebraic Techniques and Semidefinite Optimization) at MIT.

Visit the code repository <a href="https://github.com/jkoszut2/ConicSolver">here</a> or browse the final report <a href="/projects/6_7230_Project_Report_Joe_Koszut.pdf">here</a>.
